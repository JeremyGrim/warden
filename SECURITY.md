# Security Policy

Report a suspected vulnerability privately to the repository owner, through a private GitHub Security Advisory. Never publish a suspected vulnerability or a real credential in a public issue.

The latest version on `main` is supported. A report should include:

- the affected version or commit;
- the operating system and Node.js version;
- the steps to reproduce it;
- the estimated impact.

What Warden reads and sends is described in [docs/security.md](docs/security.md).
